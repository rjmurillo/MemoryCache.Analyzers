# SRC1000: Avoid System.Runtime.Caching.MemoryCache in .NET Core+

## Summary

Avoid creating `System.Runtime.Caching.MemoryCache` in modern .NET projects.
Use `Microsoft.Extensions.Caching.Memory` instead.

## Rule description

SRC1000 reports an object creation expression when all of these conditions are met:

- The source language is C#.
- The created type is `System.Runtime.Caching.MemoryCache` or derives from it.
- The compilation does not target .NET Framework.

The analyzer does not report `MemoryCache.Default` or other member access,
including calls to methods such as `Get` and `Set`.

Microsoft recommends `Microsoft.Extensions.Caching.Memory.IMemoryCache` over
`System.Runtime.Caching.MemoryCache` for ASP.NET Core because it integrates with
dependency injection. Microsoft describes `System.Runtime.Caching.MemoryCache`
as a compatibility bridge for porting from ASP.NET 4.x.

## Diagnostic message

> Do not use System.Runtime.Caching.MemoryCache in .NET Core or .NET 5+. Use Microsoft.Extensions.Caching.Memory instead.

## How to fix violations

Replace the `System.Runtime.Caching.MemoryCache` object creation with
`Microsoft.Extensions.Caching.Memory.MemoryCache`.

For the full API mapping and the behavior changes, see
[Migrate from System.Runtime.Caching.MemoryCache](../migrating-from-system-runtime-caching.md).

### Before

```csharp
using System;
using System.Runtime.Caching;

public static class CacheExample
{
    public static void Store()
    {
        MemoryCache cache = new("orders"); // SRC1000
        cache.Set("order:42", "ready", DateTimeOffset.UtcNow.AddMinutes(5));
    }
}
```

### After

```csharp
using System;
using Microsoft.Extensions.Caching.Memory;

public static class CacheExample
{
    public static void Store()
    {
        using MemoryCache cache = new(new MemoryCacheOptions());
        cache.Set("order:42", "ready", TimeSpan.FromMinutes(5));
    }
}
```

### Use dependency injection

ASP.NET Core applications can register the cache with `AddMemoryCache` and
request `IMemoryCache` from dependency injection:

```csharp
using System;
using Microsoft.Extensions.Caching.Memory;
using Microsoft.Extensions.DependencyInjection;

ServiceCollection services = new();
services.AddMemoryCache();

using ServiceProvider serviceProvider = services.BuildServiceProvider();
IMemoryCache cache = serviceProvider.GetRequiredService<IMemoryCache>();
cache.Set("order:42", "ready", TimeSpan.FromMinutes(5));
```

## When to suppress

Suppress SRC1000 when the compatibility API is required during a migration and
replacing it is not yet practical:

```csharp
using System.Runtime.Caching;

public static class LegacyCacheFactory
{
    public static MemoryCache Create()
    {
#pragma warning disable SRC1000
        return new MemoryCache("legacy");
#pragma warning restore SRC1000
    }
}
```
