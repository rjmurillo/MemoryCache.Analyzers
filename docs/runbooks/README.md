# Runbooks

Short, step-by-step guides for releases and CI problems.

- [Release a new version](release.md): bump the version, tag, and publish to
  NuGet.
- [Publish failed](publish-failed.md): fix a failed `Release publish`
  workflow run.
- [Bad release](bad-release.md): unlist a broken version and ship a fixed one.
- [CI failures](ci-failures.md): fix common build and test failures.
